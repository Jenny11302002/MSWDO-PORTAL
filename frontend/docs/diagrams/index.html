MSWDO Online Service Portal

A public-facing social welfare service portal with client accounts, staff case processing, document uploads, request tracking, appointments, and administration. The diagrams are grounded in the current React/Vite frontend, Laravel API, MySQL models, and Docker Compose configuration.

Essential structural blueprint

System Architecture is the key infrastructure view: it shows the browser, React client, Laravel API, database, and private upload storage and how they connect.

Critical behavior views

Use Case defines the Applicant, Client, Staff, and Administrator capabilities. Activity details the submission flow, including validation, reference generation, and optional uploads.

Data flow

User-entered service and applicant details go from the React form to the Laravel API for validation. A valid request is saved in MySQL with a generated reference and pending status; supporting files are stored on the backend local disk and their metadata in MySQL.
